# 🏙️ The Pinnacle Mohali - Luxury Real Estate Landing Page

A premium, high-end responsive landing page for **The Pinnacle (by STJ Group, Mohali)**. Built using modern web standards, focusing on a clean corporate layout, luxury color palettes, and seamless user experience.

## ✨ Key Features & Technical Implementations

- **Tailwind CSS v4 Configuration:** Implemented the latest CSS-first utility configuration with dynamic theme variables.
- **Glassmorphic Sticky Navbar:** Designed a fixed top navigation bar featuring `backdrop-blur` and custom opacity adjustments (`bg-[#001e36]/90`) for fluid desktop-to-mobile scrolling.
- **Pixel-Perfect Metrics Section:** Implemented an iconic "The Pinnacle in Numbers" grid featuring thin horizontal separators and structured golden vector branding icons.
- **Advanced Layout Techniques:** Mastered the use of negative margins (`-mt-[80px]`) combined with top padding (`pt-[120px]`) to allow content layers to overlap beautifully beneath a transparent layout.
- **Advanced Typography Optimization:** Applied custom utility combinations like `leading-relaxed` for superior reading comfort and `drop-shadow` to guarantee crisp visibility of white elements against multi-textured premium background images.
- **Fully Responsive Layout:** Utilized mobile-first utilities along with responsive breakpoints (`md:`, `lg:`) to ensure seamless readability on tablets, mobiles, and large screens.

## 🛠️ Tech Stack Used

- **HTML5:** Clean structural semantic elements.
- **Tailwind CSS v4:** Modern inline styles, grid layouts, custom flex systems, and responsive layouts.
- **Google Fonts:** Premium typography styling using *Jost*.

## 📂 Project Structure

- `index.html` — Main semantic markup structure.
- `src/input.css` — Core stylesheet container utilizing the modern `@theme` directive.
- `src/output.css` — Compiled production stylesheet generated by Tailwind CLI.
- `images/` — Optimized image assets and customized geometric golden vector layout elements.
